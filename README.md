# SDESE
The relevant analysis code and scripts are available at https://github.com/pmglab/SDESE.
SDESE has been integrated into the PSC platform (https://pmglab.top/psc/). 
It is also available through KGGSUM (V2.0.0, https://pmglab.top/kggsum/) for SDESE analysis and KGGSNV (https://pmglab.top/kggsnv/) for simulated data generation.
